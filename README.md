# Campfire Tales

A private social network for tabletop RPG campaigns, where players share knowledge, track relationships, and build the story together.

## Status

Early development.

The project is currently in the product discovery and architecture phase. Core concepts, domain models, and technical decisions are still being defined.

## Vision

Campfire Tales aims to help RPG groups build and preserve a shared memory of their campaigns.

The platform will focus on:

* NPCs and characters
* Player perceptions and relationships
* Shared and private campaign knowledge
* Sessions, quests, and locations
* Campaign history and events
* Information controlled by the Game Master

The Game Master controls the campaign's world state and what information is revealed, while each player maintains their own knowledge and perception of the world.

## Development

The project is open source and currently under active development.

Documentation and implementation details will be added as the architecture and product evolve.
